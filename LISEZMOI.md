# Ajouter le fichier tests-api.yml sur GitHub

Ce fichier lance les tests automatiquement à chaque mise à jour du dépôt **mediatheque-tests-api**.

## Étapes

1. Mets d'abord tout le projet **mediatheque-tests-api** sur GitHub, comme d'habitude.
2. Ouvre ce lien dans ton navigateur :
   https://github.com/ania-sekhi/mediatheque-tests-api/upload/main/.github/workflows
3. Glisse le fichier **tests-api.yml** dans la page.
4. Clique sur **Commit changes**.

Le fichier se range tout seul dans le dossier `.github/workflows`.

## Vérifier

Ouvre l'onglet **Actions** du dépôt : une coche verte ✅ apparaît au bout de quelques minutes.

> Si le lien affiche une erreur, remplace `main` par `master` dans l'adresse.
